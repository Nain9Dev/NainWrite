# Proposal Reading Sample

## Scope

This task exercises the existing agent without changing runtime behaviour.

- R1: When preparing the reading sample, the operator shall retain the original application programme and use other programme guidance only as a writing reference.
- R2: When condensing the private draft, the operator shall keep the source untouched, avoid unsupported implementation claims and retain the condensed input and generation evidence outside version control.
- R3: When generating the sample, the workflow shall use the existing local writer and auditors and preserve all review findings.
- R4: Before producing English variants, the workflow shall require human approval of the exact Spanish revision under the existing approval contract.
- R5: When delivering a PDF sample, the operator shall verify that it renders as one readable page without altering the generated prose during export.

The sample is not a complete application or an eligibility assessment. No runtime changes, submission, commit or push are included.
