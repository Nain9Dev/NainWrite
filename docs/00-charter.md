# Project Charter

## Objective

Build a local, reproducible evaluation workflow for Spanish rewriting that prioritizes semantic fidelity over stylistic variation.

## Current phase

The project is creating and approving a Spanish-from-Spain benchmark before implementing a model runner or English translation.

## Success condition

A benchmark version is useful only after its references have been reviewed by Aitor and its structural validation remains green.

## Boundaries

- Local and zero-cost tooling first.
- No confidential client text in the initial benchmark.
- No automatic publication.
- No translation until the Spanish rewriting gate is closed.
